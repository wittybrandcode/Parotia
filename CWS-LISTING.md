# Parotia — Chrome Web Store Listing

## Short Description (132 chars max)

Freeze, inspect, clean and capture news pages as broadcast-ready PNGs.

## Detailed Description

**Freeze. Inspect. Clean. Capture.**

Parotia turns any news webpage into a broadcast-ready PNG in seconds. Built for editorial teams who need clean, professional screenshots without the noise.

**Core workflow:**

1. **Freeze** — Lock the page against live updates, ad refreshes, and DOM mutations. What you see is what you capture.
2. **Inspect & Pick** — Hover over any element to highlight it. Pick elements to understand the page structure.
3. **Clean** — Delete unwanted elements (ads, banners, cookie notices, popups) with a single click. Keep elements you want to protect.
4. **Capture** — Export the cleaned page as a high-resolution PNG, ready for broadcast or print. Select a specific region if you only need a portion.

**Key features:**

- **Smart presets** — Create, save, and auto-apply cleanup rules per website. Visit the same news site twice and Parotia remembers what to remove.
- **Free-select capture** — Draw a custom region on the frozen page and capture just that area.
- **Element protection** — Mark elements to keep so cleanup never removes them.
- **Undo support** — Every delete is reversible. Made a mistake? Undo it instantly.
- **Zero network activity** — Parotia never phones home. No data collection, no analytics, no servers. Everything runs locally in your browser.
- **Keyboard shortcuts** — Shift+Alt+F to freeze, Shift+Alt+P to pick, and more for power users.

**Permissions explained:**

Parotia requests only the permissions it needs to function. It uses `activeTab` to access the current page when you click the icon, `scripting` to inject its toolbar, `storage` for your presets, `downloads` to save captured images, and `tabs` to manage zoom levels during capture. No data ever leaves your browser.
