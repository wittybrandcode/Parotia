NEWSCLEAN — اختصارات لوحة المفاتيح
===================================

ملاحظة: الاختصارات تعمل بعد تشغيل الإضافة على الصفحة، ولا تعمل أثناء الكتابة في
حقول الإدخال (input / textarea). لا تستخدم Ctrl أو Cmd إطلاقاً لتجنّب تعارض مع المتصفح.

----------------------------------------------
الاختصار            الإجراء
----------------------------------------------
Shift+Alt+F         تجميد الصفحة / إلغاء التجميد (تبديل)
Shift+Alt+P         بدء / إيقاف الالتقاط (Pick) — تسمية العناصر
Escape              إيقاف الالتقاط وإغلاق شريط العنصر (أثناء الالتقاط فقط)
Delete أو Backspace حذف العنصر المحدد (أثناء الالتقاط ومع وجود اختيار فقط)
----------------------------------------------

خطوات سريعة للتنظيف:
1) Shift+Alt+F  -> تجميد الصفحة
2) Shift+Alt+P  -> بدء الالتقاط
3) حرّك المؤشر فوق الفوضى، ثم:
   - Delete             -> حذف العنصر
   - Delete Similar     -> حذف المتشابهات (من شريط العنصر)
4) Escape          -> إنهاء الالتقاط
5) Shift+Alt+F     -> إعادة تفعيل الصفحة عند الانتهاء
