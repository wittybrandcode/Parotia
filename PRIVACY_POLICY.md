# Parotia — Privacy Policy

**Effective date:** August 17, 2026

## Overview

Parotia is a Chrome extension that helps editorial teams freeze, inspect, clean, and capture news web pages as broadcast-ready PNG images. It operates entirely on your local machine — no data is sent to any server.

## Data Collection

**Parotia collects no data.** The extension does not transmit, collect, store, or share any personal information, browsing history, or usage analytics.

## Data Storage

All data generated by Parotia is stored locally in your browser using `chrome.storage.local`:

- **Preset configurations** — cleanup rules you create or import.
- **Capture staging data** — temporary image data used during the capture process. This data is automatically purged when it is no longer needed.

No data is transmitted to external servers, cloud services, or third parties.

## Permissions

Parotia requests the following permissions:

| Permission | Purpose |
|------------|---------|
| `activeTab` | Access the currently active tab when you click the extension icon, to inject the toolbar and perform captures. |
| `scripting` | Inject content scripts into the active tab for freeze, inspect, and capture functionality. |
| `storage` | Store your preset configurations and temporary capture data locally. |
| `tabs` | Control zoom levels during element capture and restore them afterward. |
| `unlimitedStorage` | Store large full-page capture images temporarily during the capture process. Standard storage quotas are insufficient for high-resolution full-page screenshots. |
| `downloads` | Save captured PNG images to your downloads folder. |

## Network Activity

Parotia makes **no network requests**. It does not connect to any external server, API, or analytics service.

## Third-Party Code

Parotia does not load, execute, or reference any third-party scripts, libraries, or resources from external sources.

## Changes to This Policy

If this privacy policy is updated, the changes will be published in the Parotia GitHub repository and reflected in the Chrome Web Store listing.
